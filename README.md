# Billiards-Trainer
A visual billiards training tool for practicing shots, banks, kicks, English, speed, and diamond systems — built for players, instructors, and projected table training.

## Temporary Guide development preview

This branch is deployed separately at https://billiards-trainer-guide-dev.vercel.app and must not be merged into `main` before acceptance. The production trainer is unchanged. This initial deployment is a connectivity checkpoint; the integrated narration build remains pending upload.
