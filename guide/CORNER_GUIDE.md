# Corner marking for portrait and landscape images

Toolbar order: Choose Image, Find / Add Corners, Reset Corners, Custom Table Layouts, Corner Sensing. Find / Add Corners opens the numbered diagram and resumes manual marking without erasing existing points. Custom Table Layouts opens the region and diamond-alignment panel.

Manual marking follows the same table references in either image orientation: P1, P3, P4, P6 for the full table, or highlighted region boundary points for partial coverage. The first two references follow one long rail, rather than the screen’s top edge.

Corner Sensing orders the estimated quad along the longer pair of opposing sides, rotating portrait estimates before calibration. Cloth detection cannot identify the real head/foot end; the status and audio require checking the numbered orientation against the diagram and using manual marking if reversed. This is an estimate, not automatic semantic recognition of the table ends.

Get Started uses one coherent Chase corner walkthrough. All ten new/replaced clips use Chase and are paced against Target landing precision. Add Missed Ball adds one entry per activation and automatically turns off after a valid placement. Invalid taps do not consume the placement; another ball requires pressing the button again.
