Billiards Trainer for Windows

Billiards Play now has a photographic lounge entrance, polished glass controls, and 20 individually selected game images. Each Explore all 5 link opens a category page with five staggered game choices and return links to Play and All 20 games. The Shot Clock uses glossy black dials and coordinated glass panels. Companion Play remains unchanged. All new page artwork is included in the offline app and local-table host.

The Trainer's new Camera Recorder captures 2D/3D viewpoint changes and transition footage without executing a shot. Its floating Record, Pause/Resume, Stop and view-mode controls support Full Table, Current View, Table + Stroke, and Full Screen where Chrome Element Capture is supported. Camera clips save as individual MP4 files and may also be inserted between executed shots in a combined session recording. The floating recorder stays out of captured footage.

Guide now includes every lesson in a consistent numbered order, with advanced lessons visible and a remembered Auto preference. Quick Start uses stable lesson/checkpoint IDs; Previous and rewind navigation preserve the expected sequence. The release is gated on complete Guide and Quick Start playback checks inside the offline native web view.

Includes Trainer, Zen, Play, guided layouts, all narration, trained photo-analysis models and the local ONNX/WASM runtime. Normal app pages and audio load from the installation folder; internet connectivity does not select a different runtime path. The existing save-data origin and local game/layout storage are retained.

Local table hosting and private player connections remain available on a shared private Wi-Fi network, without internet. Internet is needed to download the installer and, if absent, the Microsoft WebView2 prerequisite. Feedback forms and external websites still require internet.
