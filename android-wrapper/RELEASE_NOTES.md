Billiards Trainer for Android

The Trainer's new Camera Recorder captures 2D/3D viewpoint changes and transition footage without executing a shot. Its floating Record, Pause/Resume, Stop and view-mode controls support Full Table, Current View, Table + Stroke, and Full Screen where Chrome Element Capture is supported. Camera clips save as individual MP4 files and may also be included between executed shots in a combined session recording. The floating recorder stays out of captured footage.

Guide now includes every lesson in a consistent numbered order, with advanced lessons visible and a remembered Auto preference. Quick Start uses stable lesson/checkpoint IDs; Previous and rewind navigation preserve the expected sequence. The release is gated on complete Guide and Quick Start playback checks inside the offline native web view.

Zen, Trainer, Play, all 243 Chase recordings, guide audio, and photo-analysis models/runtime are installed in the APK. App content opens directly from installed files; there is no first-launch website download.

This release keeps the permanent Billiards Trainer signing key, application IDs, and HTTPS save-data origin so compatible existing installations can update in place without deleting saves. If an older debug-signed installation is still present, a one-time backup and reinstall may be necessary: save and verify data using Play → Tools → Back up / restore saved data before uninstalling. Uninstalling without a verified backup removes app-only saves.

Internet is needed to download updates, use feedback/email forms, or open external websites. Devices sharing a local table still need the same private Wi-Fi. The separate Android Play preview's hosting/hotspot and device-dependent speech adapters are not added to the standard app in this packaging update.
