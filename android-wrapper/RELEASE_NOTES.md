Billiards Trainer for Android

Zen, Trainer, Play, all 243 Chase recordings, guide audio, and photo-analysis models/runtime are installed in the APK. App content opens directly from installed files; there is no first-launch website download.

Install this update over the existing app. The application ID, signing certificate and HTTPS save-data origin are retained; local games, layouts and the image archive are preserved. The separate Installer app keeps its existing identity too.

Internet is needed to download updates, use feedback/email forms, or open external websites. Devices sharing a local table still need the same private Wi-Fi. The separate Android Play preview's hosting/hotspot and device-dependent speech adapters are not added to the standard app in this packaging update.
