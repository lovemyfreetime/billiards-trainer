Standalone ChromeOS PWA installation

Install on Chromebook

  1. Tap Open Chromebook App.
  2. When Chrome offers installation, choose Install. If needed, use Chrome's menu and choose the option to install/create an app shortcut.
  3. Launch Billiards Trainer from the Chromebook launcher and pin it to the shelf if desired.
  4. Once its offline cache is populated, the app can run without Internet.
