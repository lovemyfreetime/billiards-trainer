Install Billiards Trainer

  1. Tap OPEN CHROMEBOOK APP.
  2. Inside the trainer, tap the green INSTALL CHROMEBOOK APP button when it appears.
  3. After installation, launch it from the Chromebook launcher and pin it to the shelf if desired.
