Install on Windows 11

  1. Tap Download Windows Edition.
  2. Extract the ZIP file.
  3. Open the extracted folder and double-click Install Billiards Trainer.cmd.
  4. The installer creates the app-style shortcut. The trainer opens without normal browser tabs or an address bar.
