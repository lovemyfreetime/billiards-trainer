Install Billiards Trainer

  1. Tap DOWNLOAD WINDOWS INSTALLER.
  2. Extract the downloaded ZIP.
  3. Open the extracted folder. At the top level there is one installer: INSTALL BILLIARDS TRAINER.cmd.
  4. Double-click it. The other app files are kept inside the support folder so there is nothing else to choose.
