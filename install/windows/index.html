Installer Instructions

Download the installerTap INSTALL BILLIARDS TRAINER, then open Billiards-Trainer-Windows-Setup.exe.
If Windows shows a security messageBecause this beta is not yet code-signed, Microsoft Defender SmartScreen may appear. Choose More info, then Run anyway.
InstallFollow the short setup prompts. The installer creates normal Desktop and Start-menu shortcuts.
Open Billiards TrainerZen, Trainer, Play, recorded audio, and photo analysis are installed on your computer and open without internet. The app opens maximized in its own window. Press F11 for complete fullscreen.

Host a local Play table

The Windows installer now includes local hosting. Open Billiards Play - Local Host from your Start menu, choose a game, and open Local table to show the joining QR code.

Players connect to the same trusted private Wi-Fi, scan the code, and enter their names. Approve their seats on the host to unlock their private cards or assignments. Players can enable spoken turn alerts while their screens stay open and awake. No player account, separate player installation, or internet connection is needed during play.

Keep the host running. If Windows asks for network access, allow it on the private network you are using. Android, iPhone, iPad, and Chromebook browsers can join as players; this first host runs on Windows.
