Install the current AI version

This installer opens the same current AI Camera Edition used by the GitHub web app. It creates a Windows desktop/Start Menu shortcut and opens the trainer in its own Edge/Chrome app window, without normal browser tabs.

  2. Right-click the ZIP and choose Extract All.
  3. Open the extracted folder and double-click INSTALL BILLIARDS TRAINER AI.cmd.
  4. The new Billiards Trainer AI shortcut always opens the current GitHub AI build.
