Back up and restore saved data

Open this page inside the app that holds your saves. A browser has its own separate saved data.

Backups include saved layouts, game and tournament settings, saved session files, and the app’s image archive. Files already saved in Downloads or Pictures stay in those folders. Folder permissions must be selected again after reinstalling.

Your old Android app cannot save this file directly. Copy the backup text into a text editor and save it as Billiards-Trainer-Backup.json. Verify that the saved file contains the complete text before uninstalling. You can also long-press the text above and choose Select all → Copy.

Backup confirmed. Keep that copy until your saved data has been restored successfully.

Restore a backup

Select your saved JSON file, or paste its complete text above. Restore merges records and replaces settings with matching names. Back up this device’s current data first.
